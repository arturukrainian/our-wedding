# Проєкт: Wedding Invite — зафіксовані домовленості

Оновлено: 2026-03-04

## 1) Стек і формат проєкту
- Тип: статичний сайт (Vanilla HTML/CSS/JS).
- Фреймворки: не використовуються (без React/Next).
- Основні файли:
  - `index.html`
  - `styles.css`
  - `script.js`

## 2) Загальна логіка секцій і навігації
- Кожна секція `main > section` має висоту `130%` від `--screen-height`.
- Кнопка `↓` (slide-next) скролить до **центру наступного блоку**.
- Кнопка ховається, якщо наступного блоку немає.

## 3) Прелоадер
- Є кастомний прелоадер із “кільцями” (minimal interlock).
- Під час відкриття:
  - кільця переходять `t=0.55 -> t=1`,
  - потім викликається `hidePreloader()`.
- Прелоадер не блокується на аудіо autoplay.
- Відкриття сайту відбувається для всіх сценаріїв відео:
  - `ready`
  - `timeout`
  - `error`
- Для `prefers-reduced-motion` — майже миттєве відкриття.

## 4) Hero media
- Hero video:
  - шлях: `assets/video/start-video.mp4`
  - `poster`: `assets/img/hero-poster.jpg`
  - атрибути: `autoplay muted loop playsinline preload="metadata"`.
- Готовність відео:
  - `loadeddata` / `canplay` / `readyState >= 2`,
  - fallback timeout: `10s`,
  - `error` обробляється.

## 5) Dress Code (поточна домовленість)
- Секція використовує **локальне** зображення:
  - `dress-code.jpg` (в `index.html` через `<img>`).
- Вимоги:
  - без обрізання зображення,
  - `width: 100%`,
  - `height: auto`,
  - `display: block`.
- Секція має фон-заповнення:
  - `#F7F3E8`.
- Зображення прелоадиться завчасно:
  - `<link rel="preload" as="image" href="dress-code.jpg">`,
  - `loading="eager"`, `fetchpriority="high"`.

## 6) Фони секцій (узгоджені файли)
- `location.jpg` — блок локації (`.venue`).
- `suggest.jpg` — блок побажань (`.wishes`).
- `end.jpg` — фінальний блок з таймером (`.countdown`).

Примітка: якщо стиль/оверлеї для цих трьох блоків змінюються, узгоджувати окремо (насиченість, затемнення, читабельність тексту).

## 7) Календар
- Календар має reveal-анімацію по входу в viewport (одноразово):
  - title -> weekdays -> days (stagger),
  - кульмінація: акцент на `26`.
- `26` позначено через `data-day="26"` і має окрему обвідку/анімацію.
- Для `prefers-reduced-motion` анімації вимикаються.

## 8) Таймер (мовні форми)
- Підписи таймера змінюються автоматично:
  - день / дні / днів
  - година / години / годин
  - хвилина / хвилини / хвилин
  - секунда / секунди / секунд

## 9) Поточна структура кінця сторінки
- `RSVP` (анкета) — **потрібна**, залишається.
- Footer — **прибраний**.
- Таймер — останній секційний блок.

## 10) Правило для майбутніх змін
- Не змінювати без додаткового погодження:
  - висоту секцій (`130%`),
  - логіку скролу кнопки `↓` (центр наступної секції),
  - поведінку прелоадера й fallback-сценарії,
  - використання локальних медіа (video/image paths),
  - наявність `RSVP` і відсутність footer.

Якщо потрібен відступ від цих пунктів — спочатку коротке погодження, потім правки.
